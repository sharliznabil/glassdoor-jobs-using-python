# Glassdoor Jobs - Data Analysis using Python

This project analyzes job postings from Glassdoor to extract valuable insights about salaries, job roles, required skills, and company attributes. The analysis is performed using Python and popular data manipulation and visualization libraries.

## 🎯 Objectives

- Clean and preprocess job data scraped from Glassdoor.
- Analyze salary estimates and company ratings.
- Extract key skills from job descriptions.
- Explore job location trends and industry distribution.

## 🗂️ Dataset

The dataset consists of job postings scraped from [Glassdoor](https://www.glassdoor.com), containing the following fields:

- Company Name
- Salary Estimate
- Job Title
- Job Description
- Location
- Headquarters
- Company Rating
- Founded Year
- Industry
- Sector
- Revenue

## 🛠️ Tools & Libraries

- Python
- Pandas
- Numpy
- Matplotlib


## 📊 Key Analyses

- **Salary Breakdown:** Minimum, maximum, and average salaries across job roles.
- **Skill Extraction:** Frequency of technical skills like Python, SQL, Excel, etc., from job descriptions.
- **Company Info:** Analysis of company size, revenue, and ratings.
- **Geographical Insights:** Popular job locations and cities with high demand.
- **Job Titles:** Most common roles and how they relate to salary.

## 📈 Visualizations

- Bar plots for average salaries per role
- Pie charts showing skill frequency
- Box plots for salary distributions
- Heatmaps of correlations between features

## 📌 Sample Insights

- Data Scientist and Analyst roles often require Python and SQL.
- Larger companies tend to offer more competitive salaries.
- California and New York are hotspots for data-related jobs.

## 🚀 Future Enhancements

- Add machine learning models to predict salaries.
- Perform sentiment analysis on company reviews (if available).
- Automate web scraping with updated Glassdoor data.
